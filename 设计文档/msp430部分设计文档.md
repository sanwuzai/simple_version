### 设计文档

### Msp430部分

#### 通信协议

MSP430到PC数据传输：格式:|A5|5A|数据类型|数量|数据高位|数据低位|数据高位|数据低位|......|。

数据类型00表示温度、FF表示电压;

数量为用二进制表示的发送的数据的数量，温度模式时数量为1，电压波形模式时数量为8，电压触发模式时数量为128。

温度或电压直接传原始值，占两个字节，高位在前低位在后。

#### 指令协议

握手状态下等待PC端发送”F0”握手，收到后进入空闲状态；

空闲状态下”FF”启动采样；也可接收PC端发来的配置信息调整外设设置。

工作状态下收到”00”则停止采样回到空闲状态。

模式选择指令”AA”为温度连续模式，”BB”为电压波形模式，”CC”为电压触发模式。

#### 状态表

| **状态** | statecode | **行为** |   |
| --- | --- | --- | --- |
| 握手 | handshake |每 0.5 s 发一次 '=' | 收到”F0”进入空闲状态 |
| 空闲 | idle |等待下一步指令/调整采样模式。 | 收到”FF”进入采样状态；收到配置信息则调整。 |
| 工作 | working |开始按照选择的模式工作 | 工作完成后/收到退出指令后回到空闲 |

#### 数据流

ADC采样模块采集数据。打包模块从adcBUF取出原始值，按格式写入发送队列；发送模块从发送队列逐字节发送。

串口接收中断负责调用指令模块去解析 PC 命令并修改 state。

#### 模式：

温度模式：每0.5s采样一次温度数据并发送。

电压波形模式：每5ms采集一次电压并放入发送队列，队列满8个数据后开始发送。

电压触发模式：先采集64个点并求和作为基准，与第64个点x64的积做比较，计算代表点电压的差值，如果差值绝对值大于0.2V就保留这64个点并且再采集64个新的点发送,发送完后回到空闲；如果差值小于0.2v则继续采集下一个点并替换最老的点，重复上述检测流程。

后续可能增加新的模式

**代码框架**
    
    state = handshake;
    mode = temperature; 
    bsp_init();//初始化通用的参数
    switch (state) {
        case handshake: ......;     break;
        case idle:      ......;     break;
        case working :  working();  break;
    }


#### 功能模块部分（各个模块用文件形式分隔）

**初始化模块bsp_init.c/h**:
    
    BspInit():关闭看门狗，配置时钟为1_MHz,配置输入输出串口，timerA定时5ms。串口波特率设置为9600。(用于初始化)

**TimerA模块timer_A.c/h**:
    
    Delay(int n):开启TimerA中断并进入低功耗模式，等待TimerA中断(5ms)恢复，重复n次。(用于延时n拍)

**指令处理模块command_process.c/h**:

    CommandAnalyze(command):
        switch command {
            case 0XF0: handshake(); break;
            case 0xFF: Start();     break;
                ......
            (修改阶段调用对应函数)
            case 0xAA: if(state == idle) mode = temperature; break;
            (调整模式直接在函数内调整)    
                ......    
        }
    handshake():if(state == handshake)  进入idle。
    start():    if(state == idle)       进入working。
    Stop():     if(state == working)    回到idle。
                ......


**工作模块Working.c/h**:
    
    working(): 根据当前mode选择调用Temp(),Wave(),Trigger()
    Temp():通过TimerA延时，每0.5s采样一次温度并发送（调用采样及发送模块）
    Wave():通过TimerA延时，每5ms采样一次电压并放入发送数组，满八个后发送。发送完后重复继续采集。
    Trigger():先采集64个点并求和作为基准，与第64个点x64的积做比较，计算其数值代表的电压的差值，如果差值绝对值大于0.2V就保留这64个点并且再采集64个新的点发送,发送完后回到空闲；如果差值小于0.2v则继续采集下一个点并替换最老的点，重复上述检测流程。

**(工作模块使用)采样及发送模块Sampler.c/h**:
    
    Sample():开启adc中断并进入低功耗模式，等待adc采样完成中断后恢复。
    Pack(): (需要全局变量PackBit)
        if (PackBit == 0) 放入0xA5,再次调用Pack(),break;
        if (PackBit == 1) 放入0x5A,再次调用Pack(),break;
        if (Packbit == 2) 根据mode放入00或FF,再次调用Pack(),break;
        if (Packbit == 3) 根据mode放入0或8或128,再次调用Pack(),break;
        if (Packbit > 3 ) 从adc取出数据放入数组,break;
    send(): 从发送数组中依次取出数据放入发送buf,等待发送完成中断后放入新的数据。重复直到发送数组空。
